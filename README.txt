LAUNDRY SYSTEM (NetBeans / Java Swing / MySQL / FlatLaf)

1. Run schema.sql in MySQL (creates laundry_db + sample services).
2. Put flatlaf.jar and mysql-connector-j.jar in the lib/ folder (see lib/README.txt).
3. NetBeans: File > Open Project > select this folder > Run (F6).
4. DB login is in src/laundry/DB.java (default: root, empty password).
