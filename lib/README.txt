Put these 2 jars in this folder, with EXACTLY these file names:

  flatlaf.jar              (download flatlaf-3.x.jar from https://repo1.maven.org/maven2/com/formdev/flatlaf/ and rename it)
  mysql-connector-j.jar    (download from https://dev.mysql.com/downloads/connector/j/ -> "Platform Independent" -> rename the jar inside)

If you keep the original file names instead: in NetBeans, right-click the project ->
Properties -> Libraries -> Classpath -> remove the 2 broken entries -> Add JAR/Folder.
